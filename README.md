# Sekiro Haptics

Haptic feedback for **Sekiro: Shadows Die Twice** on PC, driven by what happens in the game:
blocks and deflects, enemy blocks, prosthetic tools, Mikiri Counter, the stomp and Lightning Reversal.

- **DualSense** (USB): PCM haptics, adaptive triggers, optional controller-speaker sounds
- **Xbox controller**: rumble (experimental, since v0.1.0-alpha.9)

Downloads are on the **[Releases](../../releases)** page. Each ZIP contains `README.txt` with requirements,
setup and known issues. The program only reads the game's memory: it writes nothing, injects nothing and hooks nothing.

This is alpha software. Please report problems with the version number from `BUILD_INFO.txt`.
